About this dashboard

Week 02 check

Self-report gate

Each week's code-along only counts against a student once they've scored at least __SELFREPORT_MIN_SCORE__ points on that week's "W0N Code-along Activity" self-report assignment in Canvas. A student who hasn't self-reported is shown separately as "Didn't self-report," regardless of what their actual code shows — the instructor doesn't need to see a false "fail" for work nobody claimed credit for. Each "Self-report" link opens that student's submission for the matching week's assignment. Every "Self-reported, but missing something" row also spells out exactly which criteria weren't met.

Main assignment grade

Completed / 0 Grade / Not submitted comes directly from that week's graded Canvas assignment submission, not from a technical check — a literal score of 0 is shown separately from "not submitted" (no submission on file at all). Work that's been turned in but not graded yet is shown as "Completed" so the AI-usage report is still visible. Click "Grade" to open that student's submission in Canvas.

AI-usage score

A 0–100 heuristic from code-level signals — heavily/uniformly sectioned HTML/CSS comments (a stray comment or two is lightly weighted, since that's taught), inline style= or embedded <style>, JavaScript, advanced layout (grid-template-areas, clamp, aspect-ratio), animations, and high CSS rule counts. Semantic tags, CSS custom properties (variables), and CSS resets are not scored since the course requires and teaches them. Click a badge to see exactly which signals fired. This is a lead worth a look, not a verdict — false positives happen, and a real student can write clean, well-commented code.

Guardrail check

The course template ships AGENTS.md and .github/copilot-instructions.md, both instructing AI agents to tutor rather than write solutions. Each repo's copies are compared against the template original; click a non-"OK" badge on the Dashboard for details.
